# 工作日志｜2026-11-10｜窗口2 架构设计

## 1. 本轮目标
确定 Agent Loop 执行上限、异常处理和 Trace，并整合已经批准的架构设计与关键决策。

## 2. 我的初始思考
此前提出：请求入口与 Runtime 分层；Runtime 编排 Model、Tool Manager、Session、Context；Session 用 JSON 保存 messages/todos/memory/summary；Context 使用动态 10～20 消息窗口，旧摘要滚动压缩并提取重要记忆。

## 3. AI 评审与质疑
指出最大轮次应区分单请求模型决策与 Session 对话轮次；建议工具错误有界恢复、非幂等 Todo 不确定写入防重复、Trace 分开记录工具请求/执行/结果，并澄清 8 次限制不等于 8 个工具。

## 4. 我的修改与最终决策
用户明确批准：单请求最多 8 次 LLM 决策，Session 无固定对话轮次上限；可恢复工具错误回传模型继续；不确定 Todo 写入核查或停止；Trace 记录请求、执行、结果、异常并避免泄密。

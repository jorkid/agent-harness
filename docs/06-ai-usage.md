# AI 使用与问题解决记录

## 分工与决策

需求分析、架构设计和任务拆解在不同 AI 窗口进行。AI 协助整理笔试原题、列出验收场景、比较实现方案并把依赖与 DoD 写入任务清单。项目负责人确认需求和架构，批准 JSON 会话隔离、Context 动态窗口、每请求 8 次模型调用及阶段收尾。AI 提议 Runtime 返回结构化状态、保留完整工具消息组和增加长度保护，负责人确认后进入实现。[需求分析记录](logs/2026-11-09-requirements.md) · [架构讨论记录](logs/2026-11-10-architecture.md) · [架构决策](04-decisions.md) · [任务拆解](03-tasks.md)

开发 Codex 按已批准任务实现代码、编写回归和运行测试。独立审查 Codex 在共享工作树上只读复查、执行独立测试并回报差异，负责人决定修复范围及是否通过。Git 暂存和本地提交由具备仓库写权限的 VS Code 环境承担，开发窗口交接工作树和验证结果。当前 Git 历史可核对 T06/T07 的 `d67ac74`、T08 的 `540fd62`、T09 的 `6574f66` 和 T11 的 `e18eeef` 等收尾提交。[开发日志](logs/development.md)

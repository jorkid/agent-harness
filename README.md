# agent-harness

Agent 测试与评测脚手架（Agent Harness）。

## 项目简介

本项目用于搭建一个可复用、可评测的 Agent 运行框架，包含 Agent 核心代码、测试代码以及完整的工程文档。

## 目录结构

```
agent-harness/
├── src/                        # Agent 核心代码
├── tests/                      # 测试代码
├── docs/
│   ├── 00-project-charter.md   # 笔试原题及协作规则
│   ├── 01-requirements.md      # 需求分析
│   ├── 02-design.md            # 架构设计
│   ├── 03-tasks.md             # 开发任务
│   ├── 04-decisions.md         # 技术决策记录
│   ├── 05-test-plan.md         # 测试方案
│   ├── 06-ai-usage.md          # AI 使用及问题解决记录
│   └── logs/
│       ├── requirements.md
│       ├── architecture.md
│       ├── development.md
│       └── testing.md
├── README.md
└── CLAUDE.md
```

## 快速开始

按 [CLI 演示](docs/cli-demo.md) 准备环境、创建与恢复会话，并查看执行 Trace。
